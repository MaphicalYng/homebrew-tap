# MaphicalYng's Homebrew Tap

[English](README.md) | [简体中文](README.zh-CN.md)

A personal Homebrew tap for prebuilt command-line tools.

## Install

Add the tap once:

```bash
brew tap MaphicalYng/tap
```

Install a package, replacing `<tool>` with its formula name:

```bash
brew install MaphicalYng/tap/<tool>
```

## Upgrade

```bash
brew update
brew upgrade MaphicalYng/tap/<tool>
```

## Uninstall

```bash
brew uninstall <tool>
```

After uninstalling all packages from this tap, you can remove it:

```bash
brew untap MaphicalYng/tap
```
